# inline-slash-autocomplete

Autocomplete Pi commands when typing `/` mid-sentence.

## Overview

A Pi extension that registers an autocomplete provider triggered by `/`. It
merges the host's built-in suggestions with fuzzy-matched slash commands so
users can invoke commands without breaking sentence flow.

## Installation

Drop into a Pi extensions directory and restart Pi.

## Usage

Type `/` followed by a command name while composing a message. Matching
commands appear in the autocomplete menu.
